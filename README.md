# lab-4-llm-decision-support

This project uses the Groq API and Llama 3.3 to build a decision-support system for microfinance loan applications.

The system:
- Summarizes loan applications
- Extracts information into JSON
- Provides decision-support briefs for loan officers

The system was evaluated for accuracy, reliability, hallucination, and responsible use.

## Files

- `Lab_4_LLM_Decision_Support.ipynb` — Main notebook
- `prompts.py` — Prompt templates
- `requirements.txt` — Required packages
- `.gitignore` — Files excluded from Git

**API keys are stored securely using Google Colab Secrets and are not included in this repository.**
